React와 Atlaskit(Atlassian Design System) 스택을 기반으로 실제 개발팀(퍼블리셔, 프론트엔드, 백엔드)이 즉시 코딩에 착수할 수 있도록 **4개 핵심 화면의 기능 명세 및 인터랙션 라우팅을 상세화한 최종 설계서**입니다.
## 📂 Screen 1. 카테고리 대시보드 (Category Dashboard)
### 1. 화면 개요 및 레이아웃
 * **목적**: 사용자가 접근 가능한 부서/업무별 폴더(카테고리)를 격자형(Grid)으로 나열하는 시스템 진입점.
 * **적용 컴포넌트**: @atlaskit/page-layout, @atlaskit/card, @atlaskit/button, @atlaskit/badge
### 2. UI 구성 요소 및 와이어프레임 상세
```
[상단 내비게이션 바]---------------------------------------------------------------------------------
📂 전사 정기 메일 스케줄 관리                                         [+ Create Category (Admin 전용)]
--------------------------------------------------------------------------------------------------
[카테고리 그리드 레이아웃: 3열(Column) 배치]
+-----------------------------------+  +-----------------------------------+  +-----------------------------------+
| 📢 인사/기획 (HR & Planning)      |  | 💻 개발/인프라 (DevOps & Infra)   |  | 💰 재무/회계 (Finance)             |
| 인사팀 정기 리포트 발송 폴더      |  | 인프라 보안 점검 자동 메일        |  | 감사 및 자금 현황 정기 메일        |
|                                   |  |                                   |  |                                   |
| 📝 스케줄: 3개   👥 권한: 그룹외 1|  | 📝 스케줄: 5개   👥 권한: dev-all |  | 📝 스케줄: 0개   👥 권한: fin-mgr  |
| --------------------------------- |  | --------------------------------- |  | --------------------------------- |
| [📂 Open Folder]   [⚙️ Permissions] |  | [📂 Open Folder]   [⚙️ Permissions] |  | [📂 Open Folder]   [⚙️ Permissions] |
+-----------------------------------+  +-----------------------------------+  +-----------------------------------+

```
### 3. 기능 및 인터랙션 명세
 * **초기 로딩 (Data Fetching)**:
   * 화면 진입 시 GET /rest/mail-scheduler/1.0/categories API를 호출합니다.
   * 현재 로그인한 유저의 세션 권한을 백엔드에서 체크하여, **권한이 있는 카테고리 레코드만 반환**받아 렌더링합니다.
   * 로딩 중에는 @atlaskit/empty-state의 스켈레톤 카드가 노출됩니다.
 * **[+ Create Category] 버튼 버튼**:
   * Confluence System Admin 또는 플러그인 관리자 권한을 가진 유저에게만 노출됩니다.
   * 클릭 시 인라인 모달(@atlaskit/modal-dialog)이 열리며 카테고리명(필수), 설명(선택)을 입력받아 POST 요청을 전송합니다.
 * **[📂 Open Folder] 클릭 시**:
   * 브라우저 리로드 없이 React State(viewMode = 'SCHEDULE_LIST', selectedCategoryId = {id})를 전환합니다.
   * 동시에 window.history.pushState를 활용해 URL 주소를 .../pages/viewpage.action?pageId=XXXX&categoryId={id}로 변환합니다.
## 🔒 Screen 2. 카테고리 권한 설정 (Permission Drawer)
### 1. 화면 개요 및 레이아웃
 * **목적**: 특정 카테고리에 접근하여 스케줄을 생성/수정/삭제할 수 있는 Confluence 내부 사용자 및 그룹을 격리 관리합니다.
 * **적용 컴포넌트**: @atlaskit/drawer, @atlaskit/select (Async 지원), @atlaskit/dynamic-table
### 2. UI 구성 요소 및 와이어프레임 상세
```
+------------------------------------------------------------- [X] Close -+
| 📋 [📢 인사/기획] 권한 제어 매니저 (ACL)                                |
| 카테고리 기본 정보 권한을 수정합니다.                                     |
|                                                                         |
|  ■ 카테고리 명 : [ 인사/기획                                          ] |
|  ■ 상세 설명   : [ 인사팀 및 기획팀 전용 발송 스케줄                  ] |
|                                                                         |
| 🔒 접근 권한 리스트                                                     |
| +-----------+------------------------------------------+--------------+ |
| | 타입      | 대상 사용자 ID / 그룹 이름                | 작업         | |
| +-----------+------------------------------------------+--------------+ |
| | [GROUP ▾] | hr-managers                              | [🗑️ Delete]  | |
| | [USER  ▾] | charlie (Confluence User Key)            | [🗑️ Delete]  | |
| +-----------+------------------------------------------+--------------+ |
| [➕ Add Row]                                                            |
|-------------------------------------------------------------------------|
|                                                     [💾 Save Changes]   |
+-------------------------------------------------------------------------+

```
### 3. 기능 및 인터랙션 명세
 * **드로어 오픈 트리거**:
   * Screen 1에서 [⚙️ Permissions] 버튼 클릭 시 오른쪽 벽면에서 width="medium" (450px) 크기로 미끄러지듯 노출됩니다.
 * **유저/그룹 동적 픽커 (User/Group Picker)**:
   * [타입] 셀렉트 박스에서 USER 선택 시, 오른쪽 대상 칸은 Confluence 순정 유저 검색 API(/rest/api/2/user/picker?query=)와 연동되는 Async Select 컴포넌트로 전환됩니다.
   * GROUP 선택 시, Confluence 내부 그룹 검색 API와 연동되어 자동완성 리스트를 뿌려줍니다.
 * **데이터 커밋 & 유효성 검사**:
   * [💾 Save Changes] 버튼 클릭 시, 화면에서 편집된 Array 데이터를 묶어 PUT /rest/mail-scheduler/1.0/categories/{id}/permissions에 JSON Body로 일괄 전송합니다.
   * **Validation**: 행 추가 후 대상 유저/그룹이 비어있는 상태로 저장을 누르면 해당 Input에 Red Alert 텍스트가 노출되며 전송이 차단됩니다.
## 📋 Screen 3. 스케줄 리스트 대시보드 (Schedule Dashboard)
### 1. 화면 개요 및 레이아웃
 * **목적**: 폴더 내부 진입 화면으로, 해당 카테고리에 바인딩된 메일 스케줄들의 동작 상태를 모니터링하고 제어합니다.
 * **적용 컴포넌트**: @atlaskit/breadcrumbs, @atlaskit/toggle, @atlaskit/flag (Toast 알림)
### 2. UI 구성 요소 및 와이어프레임 상세
```
◀ 카테고리 목록으로 (Breadcrumbs: 홈 > 📢 인사/기획)
=============================================================================================
📢 인사/기획 스케줄 리스트                                             [+ 📝 Create Schedule]
---------------------------------------------------------------------------------------------
[스케줄 카드 레이아웃: 2열 배치]
+-----------------------------------+   +-----------------------------------+
| 📢 전사 주간 보안 동향 보고        |   | 💡 팀별 핵심 성과 지표(KPI) 공유   |
| [스케줄 ID: #1]    (●) Active     |   | [스케줄 ID: #3]    (○) Inactive   |
| --------------------------------- |   | --------------------------------- |
| ⏱️ Cron: 0 0 9 * * ? (매일 09시)  |   | ⏱️ Cron: 0 0 17 ? * FRI (금 17시) |
| 📄 대상 문서: 2개  👥 수신자: 12명 |   | 📄 대상 문서: 1개  👥 수신자: 1명  |
| 📜 최근 결과: [ SUCCESS ]         |   | 📜 최근 결과: [ - 미실행 ]         |
| --------------------------------- |   | --------------------------------- |
| [⚙️ Edit]  [⚡ Run Now]  [🗑️ Delete] |   | [⚙️ Edit]  [⚡ Run Now]  [🗑️ Delete] |
+-----------------------------------+   +-----------------------------------+

```
### 3. 기능 및 인터랙션 명세
 * **뒤로가기 처리**:
   * ◀ 카테고리 목록으로 또는 브라우저 순정 [뒤로가기] 버튼 클릭 시 history.pushState 상태를 추적하여 Screen 1 메인 뷰로 컴포넌트를 즉시 스왑합니다.
 * **활성화 토글 (Active/Inactive Toggle)**:
   * 카드의 토글 스위치(@atlaskit/toggle) 변경 즉시 PUT /rest/mail-scheduler/1.0/schedules/{id}/toggle API가 비동기 호출됩니다.
   * 백엔드에서는 즉시 Quartz 쿼츠 스케줄러의 pauseJob() 또는 resumeJob() 링커를 트리거합니다. 성공 시 화면 우측 상단에 푸른색 성공 플래그(Toast)가 출력됩니다.
 * **[⚡ Run Now] (즉시 실행) 로직**:
   * 클릭 시 버튼이 로딩 스피너 상태로 변경되며 POST /rest/mail-scheduler/1.0/schedules/{id}/run API를 호출합니다.
   * 서버는 메인 웹 쓰레드를 대기시키지 않고 워커 쓰레드 풀에서 메일 발송 런타임을 즉시 기동한 뒤 성공 코드를 리턴합니다. 프론트엔드는 카드 내 '최근 결과' 셀을 [ RUNNING ] 상태로 변경하고, 완료 신호 접수 시 최신 로그 상태로 부분 리렌더링(Partial Update)합니다.
## 📝 Screen 4. 스케줄 상세 등록/편집 워크스페이스 (Edit Workspace)

 * **목적**: 단일 발송 스케줄의 주기, 대상 컨플루언스 페이지, 수신 이메일 타깃, 메일 본문 HTML 마크업을 정밀 설계하는 집중 워크스페이스.
 * **적용 컴포넌트**: Custom Sheet Container, @atlaskit/form, @atlaskit/textfield, @atlaskit/tag-group

### 3. 기능 및 인터랙션 명세
 * **진입 애니메이션**:
   * Screen 3에서 [⚙️ Edit] 또는 상단 [+ Create Schedule] 클릭 시, 화면 최하단 바닥면에서 위쪽으로 부드럽게 슬라이드 업되는 풀 오버레이 시트 레이아웃 기법을 채택합니다.
 * **Confluence Page Picker 연동**:
   * [➕ Add Confluence Page] 클릭 시 Confluence의 내부 콘텐츠 검색 레이어 API인 /rest/api/content/search?cql=type=page and title ~ "검색어" 모달 팝업이 활성화됩니다. 사용자가 타깃 페이지를 체크하면, 가상 DOM 배열에 Page ID와 Title 오브젝트가 실시간 삽입되며 목록 테이블이 동적 리렌더링됩니다.
 * **변수 토큰 삽입 기능 (Token Injection)**:
   * 우측 상단의 단축키 버튼을 클릭하면, HTML 텍스트 영역(Textarea)의 현재 커서 Focus 포인트를 자바스크립트 selectionStart API로 정밀 획득하여 치환 코드(${pageTitle}, ${pageBody} 등)를 해당 자리에 정확하게 강제 주입(Insert)합니다.
 * **최종 저장 및 트랜잭션**:
   * [💾 Save Workspace] 클릭 시 폼 내의 복합 객체 구조 데이터를 결합하여 PUT /rest/mail-scheduler/1.0/schedules/{id}로 페이로드 데이터를 보냅니다.
   * 서버 응답 성공 코드가 수신되면 시트 오버레이가 아래로 슬라이드 다운되어 닫히며, 부모 뷰인 Screen 3의 스케줄 카드 리스트가 최신 상태로 원활하게 리프레시됩니다.
